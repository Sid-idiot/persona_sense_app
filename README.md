# Big Five Personality Questionnaire with Gemini Analysis

## Overview

This application is a web-based personality assessment tool that administers the Big Five personality questionnaire and provides users with an analysis of their personality traits using the Google Gemini Pro API.  The application is designed to give users a quick and insightful overview of their personality.

## Features

1.  **Big Five Questionnaire:** Users can answer a series of questions designed to assess their personality based on the Big Five model (Openness, Conscientiousness, Extraversion, Agreeableness, and Neuroticism).
2.  **Personality Scoring:** The application calculates the user's scores for each of the Big Five personality traits based on their responses.
3.  **Gemini API Integration:** The application uses the Google Gemini Pro API to generate a personalized personality analysis and feedback based on the calculated scores.
4.  **Results Display:** The application displays the user's personality scores and the analysis generated by the Gemini API.
5.  **Clear Instructions:** The application provides clear instructions on how to complete the questionnaire.
6. **Web Interface:** The application has a web-based user interface.

## LLM API Integration

* **API Used:** Google Gemini Pro API
* **How the API is used:** The Gemini Pro API is used to generate a personalized personality analysis and feedback.  The application sends the user's calculated Big Five personality scores to the Gemini Pro API, and the API returns a text-based analysis of the user's personality, including potential strengths and areas for development.
* **Prompt Engineering:** The application uses a dynamic prompt. The prompt is constructed with the user's specific personality scores.

## Prompts

### Personality Analysis Prompt


Analyze the following Big Five personality scores:
Openness: {calculated_scores.get('O', 0):.2f}
Conscientiousness: {calculated_scores.get('C', 0):.2f}
Extraversion: {calculated_scores.get('E', 0):.2f}
Agreeableness: {calculated_scores.get('A', 0):.2f}
Neuroticism: {calculated_scores.get('N', 0):.2f}

Based on these scores, provide a brief overview of the individual's personality, highlighting potential strengths and areas for development. Offer concise and encouraging feedback for personal growth.


Explanation: This prompt is designed to instruct the Gemini Pro API to take the user's numerical personality scores and provide a helpful interpretation.  The prompt asks for a summary of the user's personality, emphasizing both strengths and areas where the user could grow.  The scores for each trait are inserted into the prompt dynamically.

## Setup Instructions

1.  **Prerequisites:**
    * Python 3.9 or later
    * Streamlit
    * Google Cloud Account
    * Google Cloud SDK (optional, but recommended for managing API keys)
    * A Google Cloud API key with the Generative Language API enabled.

2.  **Installation:**

    * Clone the repository:
        ```bash
        git clone [Your repository URL]
        cd personality-assessment-app  # Or the name of your project directory
        ```
    * Create a virtual environment (recommended):
        ```bash
        python -m venv venv
        venv\Scripts\activate  # On Windows
        source venv/bin/activate  # On macOS and Linux
        ```
    * Install the required Python packages:
        ```bash
        pip install -r requirements.txt
        ```
        (Note: You will need to create a `requirements.txt` file)

3.  **Configuration:**

    * Obtain a Google Cloud API key with the Generative Language API enabled from the Google Cloud Console.
    * Create a file named `config.py` in the project root directory.
    * Add the following lines to `config.py`, replacing `YOUR_API_KEY` with your actual API key:
        ```python
        GEMINI_API_KEY = "YOUR_API_KEY"
        ```

4.  **Running the Application:**

    * Run the Streamlit application:
        ```bash
        streamlit run persona_sense_app.py
        ```
